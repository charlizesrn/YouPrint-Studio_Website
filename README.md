## Project Overview

This website was developed by BS Information Systems students as part of their Web Development course. It showcases the services, portfolio, pricing information, customer testimonials, and contact channels of YouPrint Studio, which is a local printing and graphic design service provider.

The website serves as a professional digital platform that enables customers to learn about the business, explore available services, request price quotations, submit inquiries, and upload design files for printing and graphic design projects. Moreover, this project was developed using modern web development technologies and practices, including responsive design, accessibility standards, semantic HTML, and interactive JavaScript functionality.

## Purpose

The primary purpose of YouPrint Studio is to establish a professional online presence for a local printing and graphic design business while improving customer engagement and accessibility.

Specifically, the website aims to:

- Showcase the company's printing and graphic design services.
- Present portfolio projects and customer testimonials.
- Provide accessible service information and pricing references.
- Facilitate communication through inquiry and quotation request forms.
- Enable customers to upload design files for service requests.
- Improve the accessibility and convenience of business transactions through a centralized digital platform.

## Design Concept

The design of YouPrint Studio focuses on professionalism, accessibility, and user experience. The website was developed to reflect the creative nature of a printing and graphic design business while maintaining a clean and organized interface that allows users to easily navigate content and access services.

### Design Principles Applied

1. **Consistency**  
   Consistent use of colors, typography, visual elements, spacing, and navigation patterns was maintained throughout the website to promote a cohesive user experience and strengthen brand identity.

2. **Visual Hierarchy**  
   Content was strategically organized using headings, subheadings, imagery, and call-to-action elements to guide users' attention and facilitate efficient information processing.

3. **Contrast**  
   Appropriate contrast between colors, text, and interface elements was utilized to enhance readability, emphasize important information, and improve overall usability.

4. **Balance**  
   Visual elements, including text, images, and content sections, were arranged in a balanced manner to create an organized and aesthetically pleasing layout.

5. **White Space**  
   Adequate spacing was incorporated between sections and interface components to improve readability, reduce visual clutter, and enhance user navigation.

## Lessons Learned

The development of YouPrint Studio provided valuable experience in both technical implementation and collaborative project work. Through the project, the team gained a deeper understanding of how web technologies can be used to create effective business solutions that address real-world needs.

Key lessons learned include:

- Applying responsive web design principles to ensure compatibility across desktop, tablet, and mobile devices.
- Creating user-centered interfaces that prioritize accessibility, usability, and clear navigation.
- Implementing semantic HTML structures and accessibility features to promote inclusive web experiences.
- Integrating JavaScript functionality to enhance interactivity and improve user engagement.
- Organizing project assets and maintaining a structured codebase for easier development and maintenance.
- Using Git and GitHub for version control, collaboration, and project management.
- Understanding the importance of testing, debugging, and continuous refinement throughout the development process.
- Developing teamwork, communication, and problem-solving skills while working in a collaborative environment.

Overall, the project strengthened the team's technical competencies in front-end web development while reinforcing industry-relevant practices in design, usability, accessibility, and collaborative software development.
